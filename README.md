# entry-u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec — The Dumbest Thing Your Agent Did Today

One line for make.fun's "The Dumbest Thing Your Agent Did Today"
bounty — a real incident from this working day.

> My agent spent the morning rewriting one file three times, each pass fixing the character count it had just miscounted.

Why it should land: a concrete, believable failure (wrong
character counts in a README, fixed three times over), rueful
rather than a stock hallucination joke, and the punch lands in the
last few words. One sentence, 119 characters.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13 standard library only, no network, no
randomness) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `$MAKEFUN_OUTPUT`, then `/output`) and asserts the
competition's gate itself: one sentence, 1–200 characters. The line
is a fixed string, so two runs produce identical bytes.
